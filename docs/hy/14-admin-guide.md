# 14 — Ադմինիստրատորի ուղեցույց

Ադմինիստրատորները մուտք են գործում **http://localhost:3000** հասցեով `ADMIN` հաշվով (դեմո՝
`DEMO_ADMIN_EMAIL` / `DEMO_ADMIN_PASSWORD` `.env`-ից)։ Ինքնագրանցում չկա. հաշիվները տրամադրում է
օպերատորը։ Ինտերֆեյսը հասանելի է անգլերեն և հայերեն (EN / ՀԱՅ փոխարկիչ վերին վահանակում), իսկ
սցենարային բովանդակության յուրաքանչյուր հատված ունի փոքր **Թարգմանել** հղում, որը բնօրինակի կողքին
ցուցադրում է ըստ պահանջի թարգմանություն (ոչինչ չի պահպանվում)։

## 1. Վահանակ

Կարգավիճակի սալիկներ (ընդամենը / սևագրեր / հրապարակված / արխիվացված), հեղինակման ութքայլանի հոսքը՝
որպես ստուգացանկ, և վերջին թարմացված հինգ սցենարները՝ **Բացել** դյուրանցումով։

## 2. Սևագրի գեներացում

**Սցենար գեներացնելու համար.** մենյուում՝ *Գեներացնել* → ընտրեք **տեսակը** (`SSH կոպիտ ուժ`,
`Վտանգված հավատարմագրեր`, `Հանրային պահեստ`) → ցանկության դեպքում փոխարինեք.

| Դաշտ | Կանոն |
|-------|------|
| Վերնագիր | ազատ տեքստ, լռելյայն՝ ձևանմուշի վերնագիրը |
| Բարդություն | լռելյայն՝ ձևանմուշի բարդությունը |
| Հիմնական ակտիվ | հոսթի / օգտատիրոջ / պահեստի անուն — տառեր, թվեր, կետ, գծիկ, ընդգծում |
| Հարձակվողի IP | IPv4 (օգտագործեք փաստաթղթային միջակայքեր, օրինակ՝ `203.0.113.0/24`) |
| Տարածաշրջան | փոքրատառ լատինատառ, թվեր, գծիկներ (օրինակ՝ `eu-central-1`) |
| Հակիրճ նկարագիր | ազատ տեքստ. AI հղկումն օգտագործում է որպես ցուցումներ, հուշագրում նշվում է որպես տվյալ |
| Հղկել AI-ով | լռելյայն անջատված է. տես ստորև |

Փոխարինումները հետևողականորեն տեղադրվում են ամբողջ փաստաթղթում (ժամանակագրություն, մատյանի տողեր,
գործողություններ)։ Անվավեր մուտքը մերժվում է դաշտ առ դաշտ՝ նույն կանոններով և՛ հաճախորդի, և՛
սերվերի կողմից։

**Սպասվող արդյունք.** հայտնվում եք խմբագրիչում՝ նոր `DRAFT`-ի վրա։ *Հղկել AI-ով* միացրած դեպքում
ժապավենը նշում է աղբյուրը. `AI` (Claude-ը վերաշարադրել է նարատիվը. կառուցվածքի անփոփոխությունը
ստուգված է) կամ `FALLBACK` / `MOCK` (պահվել է դետերմինիստիկ ձևանմուշը, օրինակ՝ API բանալի չկա)։
Սևագիրը **երբեք** ինքնաբերաբար չի հրապարակվում։

**AI վարիացիա.** սցենարների ցանկում փայլուն աստղի պատկերակը ստեղծում է նոր սևագիր, որը վերապատմում
է գոյություն ունեցող սցենարը (նոր անուններ, IP-ներ, ձևակերպումներ)՝ նույնական կառուցվածքով,
բանալիներով և միավորներով։ Ստուգեք այն խմբագրիչում, ինչպես ցանկացած այլ սևագիր։

## 3. Խմբագրում

Խմբագրիչն ունի ներդիրներ. առաջին վեցը խմբագրում են սևագիրը, վերջին երեքը՝ վերլուծում այն.

| Ներդիր | Ինչ եք կարգավորում |
|-----|-------------------|
| Ընդհանուր | սլագ (ստեղծումից հետո ֆիքսված), վերնագիր, ամփոփում, նկարագրություն, բարդություն, կատեգորիա, մոտավոր տևողություն, հուշման տուգանք, հերթականության տուգանք, ուսումնական նպատակներ, միջադեպի բացատրություն, խորհուրդ տրվող լուծում |
| Ենթակառուցվածք | սիմուլյացված ռեսուրսներ՝ բանալի, տեսակ, անուն, տարածաշրջան, սկզբնական կարգավիճակ, հատկություններ (JSON) |
| Մատյաններ, ահազանգեր և ապացույցներ | ժամանակագրության գրառումներ՝ շեղում, տեսակ, կարևորություն, աղբյուր, հաղորդագրություն, ռեսուրս, **ապացույցի** նշան + նշում, և հետաքննական գործողությունը, որը **բացահայտում** է գրառումը (դատարկ = տեսանելի է սկզբից) |
| Գործողություններ և գնահատում | գործողությունների կատալոգը՝ փուլ, կատեգորիա, թիրախային ռեսուրս, **արդյունք** (EXPECTED / NEUTRAL / HARMFUL), **միավորներ**, «պետք է լինի հետո» (նախապայման), ազդեցությունը ռեսուրսի կարգավիճակի վրա, կոնսոլի ելք, բացատրություն |
| Հուշումներ | ստատիկ հուշումներ՝ ընդհանուրից մասնավոր |
| JSON | ամբողջական սահմանումը որպես JSON (ներմուծում/արտահանում) |
| Ստուգում | վավերացում + թեստային գործարկիչ + որակ + հրապարակում (տես §5) |
| Գրաֆ | կախվածությունների գրաֆը (տես §4) |
| Տարբերակներ | հրապարակված պատմությունը (տես §6) |

**Պահպանել**-ը վավերացնում է ամբողջ սահմանումը. բոլոր խնդիրները հաղորդվում են միասին (օրինակ՝
*EXPECTED-ի համար միավորները պետք է դրական լինեն*, *անհայտ ռեսուրսի բանալի*, *նախապայմանները ցիկլ
են կազմում*)։ Հրապարակված սցենարը պահպանելիս այն վերադառնում է `DRAFT`-ի (խմբագրում + 1) —
հրապարակված տարբերակը մնում է գործող սովորողի մոդուլի համար, մինչև նորից հրապարակեք։

Գործնական կանոն. EXPECTED գործողությունների միավորների գումարը դարձրեք 100, որպեսզի հում միավորը
հավասարվի տոկոսին։

## 4. Կախվածությունների գրաֆ

*Գրաֆ* ներդիրը սցենարը գծում է որպես հանգույցներ (սկիզբ, գործողություններ՝ ըստ արդյունքի գունավորված,
իրադարձություններ, ռեսուրսներ) և կողեր (`INITIAL`, `PREREQUISITE`, `REVEALS`, `TARGETS` / `EFFECT`,
`ABOUT`)։ Օգտագործեք այն՝ մեկ հայացքով նկատելու անհասանելի ապացույցը, շրջված փուլերը կամ որբ
ռեսուրսները։ Գրաֆն արտացոլում է **պահպանված** սևագիրը. երբ խմբագրիչի բովանդակությունն ավելի նոր է,
հայտնվում է «չպահպանված փոփոխություններ» նշումը։

## 5. Ստուգում. վավերացում, թեստ, գնահատում, հրապարակում

**Սևագիրը ստուգելու համար.** բացեք *Ստուգում* ներդիրը և սեղմեք **Գործարկել ստուգումները**։
Ստուգումներն աշխատում են խմբագրիչի ընթացիկ (նույնիսկ չպահպանված) բովանդակության վրա, ուստի
հետադարձ կապը կենդանի է։ Հայտնվում են երեք բաժիններ.

1. **Վավերացում** — ERROR / WARNING / INFO գտածոներ՝ կոդով, ուղով և հաղորդագրությամբ (օրինակ՝
   `EXPECTED_DEPENDS_ON_UNEXPECTED`, `NO_DANGEROUS_PATH`, `FEW_EVIDENCE`)։ Սխալներն արգելափակում են
   հրապարակումը. նախազգուշացումները միայն իջեցնում են որակի միավորը։
2. **Թեստային գործարկիչ** — երկու անցում հիշողության մեջ՝ իրական գնահատման կանոններով.
   **ճիշտ ուղին** (բոլոր սպասվող գործողությունները կախվածության կարգով. պետք է հասնի 100 %-ի,
   բացահայտի ամբողջ ապացույցը, փոխի առնվազն մեկ ռեսուրս) և **վտանգավոր ուղին** (բոլոր վնասակար
   գործողությունները. պետք է մնա տուգանված և չլուծված)։ Յուրաքանչյուր ուղի ցուցադրում է իր
   ստուգումները և բացվող քայլերի աղյուսակը։ Բաց է թողնվում, քանի դեռ վավերացումը սխալներ ունի։
3. **Որակի միավոր** — 0–100՝ վավերություն (25), թեստեր (25), ծածկույթ (20), մանկավարժություն (20),
   կառուցվածք (10), յուրաքանչյուրը՝ առաջընթացի գոտիով և հիմնավորմամբ, գումարած գնահատական.
   ≥ 85 `EXCELLENT`, ≥ 70 `GOOD`, ≥ 50 `FAIR`, այլապես `POOR`։

**Հրապարակելու համար.** վերացրեք հրապարակման վահանակում թվարկված բոլոր խոչընդոտները (վավերացման
սխալներ չկան, երկու ուղիներն անցել են, միավորը ≥ 70, սևագիրը պահպանված է), ցանկության դեպքում գրեք
փոփոխության նշում, սեղմեք **Հրապարակել որպես տարբերակ N**։ Դարպասները վերստուգվում են սերվերի
կողմից՝ պահված սևագրի վրա, ուստի ինտերֆեյսը հնարավոր չէ շրջանցել։

**Սպասվող արդյունք.** անփոփոխ տարբերակ (սահմանում + որակի հաշվետվություն + փոփոխության նշում +
հեղինակ), և սցենարը ցուցադրում է `PUBLISHED vN`։ Երեք seed սցենարները գալիս են արդեն հրապարակված՝
որպես տարբերակ 1։

## 6. Տարբերակներ

*Տարբերակներ* ներդիրը ցուցադրում է հրապարակված տարբերակները՝ ամենանորը առաջինը (համար, ամսաթիվ,
հեղինակ, որակի միավոր, փոփոխության նշում)։ Մեկը բացելիս երևում են սառեցված սահմանման ամփոփումը և
որակի բաշխումը։ **Վերականգնել**-ը տարբերակը պատճենում է խմբագրվող սևագրի մեջ (տարբերակն ինքը երբեք
չի փոփոխվում) — գործող դարձնելու համար նորից հրապարակեք։

## 7. Արխիվացում և ջնջում

- **Արխիվացնել** (սցենարների ցանկ)՝ թաքցնում է սցենարը սպառողներից. վերականգնելը այն նորից դարձնում
  է խմբագրվող `DRAFT`։ Արխիվացված սցենարները հնարավոր չէ հրապարակել մինչև վերականգնումը։
- **Ջնջել**՝ կարելի է ջնջել միայն **երբեք չհրապարակված** սևագրերը (հաստատման երկխոսությամբ)։
  Հրապարակված սցենարը պետք է արխիվացվի, որպեսզի նրա տարբերակները պահպանվեն սովորողի մոդուլի համար։

## 8. Ուսանողների քննությունները և AI գնահատումը

**Ուսանողների քննություններ** էջը ցուցադրում է սովորողի մոդուլի ուղարկած բոլոր փորձերը։ Յուրաքանչյուր տողում
հայտարարված միավորի կողքին տեսնում եք **ստուգված** միավորը, որը այս հարթակը հաշվարկել է ուղարկումը
վերարտադրելով, և `համընկնում է` / `ԱՆՀԱՄԱՊԱՏԱՍԽԱՆ` նշանը — անհամապատասխանությունը նշանակում է, որ սովորողի
մոդուլը հայտնել է գնահատական, որը մեր դետերմինիստիկ վերարտադրումը հերքում է։

Քննությունը AI-ով գնահատելու համար.
1. Բացեք փորձը։ Ձախ քարտը ստուգված արդյունքն է (միավոր, հում միավորներ, հուշումներ, ապացույցներ, բաց թողնված
   սպասվող գործողություններ). ներքևի աղյուսակը՝ յուրաքանչյուր ուղարկված գործողություն իր գնահատմամբ։
2. Սեղմեք **Կատարել AI գնահատում**։ AI-ն ստանում է սցենարը (ներառյալ լուծումը) և ստուգված վերարտադրումը —
   երբեք ուսանողի ազատ տեքստը — և վերադարձնում խորհրդատվական գնահատական 100-ից, հաղորդագրություն ուսանողի
   համար, լավ կատարվածը, սխալները և ուսումնական առաջարկությունները։
3. Գնահատումը պահպանվում է իր աղբյուրով (`Claude` կամ օֆլայն գնահատողը, երբ API բանալի չկա), և սովորողի
   մոդուլը կարող է ստանալ այն `GET /api/learner/attempts/{externalId}`-ից։ Կոճակը կրկին սեղմելը փոխարինում է
   գնահատումը։

AI գնահատականը խորհրդատվական է. ստուգված միավորն է գնահատականը, և AI-ն չի կարող փոխել այն։

## 9. Խնդիրների լուծում

| Ախտանիշ | Լուծում |
|---------|-----|
| Հրապարակման կոճակն անջատված է | Վերևում թվարկված է խոչընդոտ. չպահպանված փոփոխություններ, վավերացման սխալներ, ձախողված ուղի, միավոր < 70, կամ սցենարն արխիվացված է։ |
| Գեներացումը մերժում է մուտքը | Դաշտերի կանոնները՝ §2-ում. սերվերը նույն սխալները հաղորդում է ըստ դաշտի։ |
| AI հղկումը վերադարձնում է `FALLBACK` | `ANTHROPIC_API_KEY` չկա, ժամանակի գերազանցում, կամ AI-ը փոխել է կառուցվածքը. պահվել է դետերմինիստիկ սևագիրը — կարելի է հանգիստ շարունակել։ |
| Թարգմանել-ը ցուցադրում է անգլերեն տեքստը | Օֆլայն (`mock`) մատակարար է. իրական թարգմանության համար նշեք `AI_PROVIDER=claude`։ |

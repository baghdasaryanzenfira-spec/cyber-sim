# Առաջարկվող նկարներ ավարտական աշխատանքի համար (≈ 20)

Դիագրամների աղբյուրները փաստաթղթավորման Mermaid բլոկներն են — դրանք կարելի է գծապատկերել ցանկացած Mermaid գործիքով
(օրինակ՝ https://mermaid.live, VS Code / IntelliJ Mermaid ընդլայնումներ, կամ `npx @mermaid-js/mermaid-cli -i file.md`)։
Էկրանապատկերներ. գործարկեք համակարգը `docker compose up --build`-ով (սխեմայի վերագրումից հետո անհրաժեշտ է թարմ
տվյալների բազա՝ նախ `docker compose down -v`), մուտք գործեք `.env`-ի դեմո ադմինիստրատորով, օգտագործեք առնվազն
**1600 × 900** չափի դիտարկիչի պատուհան և լռելյայն մասշտաբ։ Երեք սկզբնական սցենարները գործարկման ժամանակ
ավտոմատ հրապարակվում են, ուստի վահանակը և սցենարների ցանկը անմիջապես բովանդակություն ունեն. գեներացրեք մեկ
լրացուցիչ սևագիր (Նկ. 16), որպեսզի տեսանելի լինեն նաև DRAFT տողերը և թարմ որակի հաշվետվությունը։

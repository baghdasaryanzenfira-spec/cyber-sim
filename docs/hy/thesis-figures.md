# Ավարտական աշխատանքի առաջարկվող նկարներ (≈ 20)

Դիագրամների աղբյուրները փաստաթղթերում առկա Mermaid բլոկներն են. դրանք կարելի է արտապատկերել Mermaid-ի ցանկացած
գործիքով (օրինակ՝ https://mermaid.live, VS Code / IntelliJ-ի Mermaid հավելումները կամ
`npx @mermaid-js/mermaid-cli -i file.md`)։
Էկրանի պատկերներ (screenshots). գործարկեք `docker compose up --build`, մուտք գործեք `.env`-ում նշված ցուցադրական
հաշիվներով, օգտագործեք **առնվազն 1600 × 900** չափի բրաուզերի պատուհան (ակտիվ սիմուլյացիան երեք սյունակ է
ցուցադրում 1536 px բովանդակության լայնությունից սկսած) և լռելյայն մասշտաբը։
Նախապես ավարտեք մեկ-երկու սիմուլյացիա, որպեսզի վահանակները և գծապատկերները տվյալներ պարունակեն։

### Որոշում. Testcontainers՝ H2-ի փոխարեն
- **Ինչու:** սխեման օգտագործում է PostgreSQL-ին հատուկ հնարավորություններ (`jsonb`, մասնակի եզակի ինդեքս, `FILTER`, `jsonb_array_elements`)։
  H2-ը կա՛մ կձախողվեր, կա՛մ այլ կերպ կվարվեր՝ տալով կեղծ վստահություն։
- **Գինը:** թեստերը պահանջում են Docker. առաջին գործարկման ժամանակ ներբեռնվում է `postgres:17-alpine` պատկերը։ Ինտեգրացիոն թեստերի բոլոր
  դասերը կիսում են մեկ Spring կոնտեքստ և մեկ կոնտեյներ (կոնտեքստի քեշավորում), ուստի թեստերի հավաքածուն մնում է արագ (~1 րոպե)։

## 4. Չընդգրկված / սահմանափակումներ
- Չկան frontend-ի ավտոմատացված թեստեր (կոմպոնենտային կամ դիտարկիչային E2E)։ Առաջարկվող հաջորդ քայլը՝ Playwright թեստեր մուտք →
  սիմուլյացիա → արդյունք հոսքի համար։
- Իրական Claude API-ն թեստավորվում է միայն mock մատակարարի միջոցով. կենդանի կանչը պահանջում է API բանալի
  (**իրականացված է, բայց գործարկման ժամանակ չի ստուգվել** այս միջավայրում)։
- Չկան ծանրաբեռնվածության/արտադրողականության թեստեր (պարտադիր չեն սպասվող լսարանային մասշտաբի օգտագործման համար)։

### Որոշում. Testcontainers՝ H2-ի փոխարեն
- **Ինչու.** սխեման օգտագործում է PostgreSQL-ին հատուկ հնարավորություններ (`jsonb` սյունակներ հատկությունների,
  մանրամասների և տարբերակների snapshot-ների համար)։ H2-ը կամ կձախողվեր, կամ այլ կերպ կվարվեր՝ տալով կեղծ
  վստահություն։
- **Գին.** թեստերը պահանջում են Docker. առաջին գործարկումը ներբեռնում է `postgres:17-alpine` պատկերը։
  Ինտեգրացիոն թեստերի բոլոր դասերը կիսում են մեկ Spring կոնտեքստ և մեկ կոնտեյներ (կոնտեքստի քեշավորում),
  ուստի փաթեթը մնում է արագ։

## 4. Չծածկված / սահմանափակումներ
- Ավտոմատացված frontend թեստեր չկան (կոմպոնենտային կամ դիտարկիչային E2E)։ Խորհուրդ տրվող հաջորդ քայլ՝
  Playwright թեստեր մուտք → գեներացում → հրապարակում հոսքի համար։
- Իրական Claude API-ն վարժեցվում է միայն mock-ված մատակարարի միջոցով. կենդանի կանչը պահանջում է API բանալի
  (**իրականացված է, բայց runtime-ում չստուգված** այս միջավայրում)։
- Բեռնվածության/արտադրողականության թեստեր չկան (սպասվող մեկ-ադմինիստրատոր օգտագործման համար չեն պահանջվում)։

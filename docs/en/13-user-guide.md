# 13 — User Guide (Learners) — moved

The learner (student) experience — registering, running incident simulations, using the AI tutor,
viewing scores and progress — is **not part of this repository**. It is developed by another team
member as a separate module.

What that module consumes from here: the **published scenario versions** (`scenario_versions`
rows). Each version is an immutable snapshot of a scenario definition that has passed validation,
both test paths and the quality threshold, together with its quality report. Drafts and archived
scenarios are never visible to learners.

Guides in this repository:

- [14-admin-guide.md](14-admin-guide.md) — the administrator's manual for authoring, validating,
  testing, publishing and versioning scenarios.
- [17-admin-authoring-platform.md](17-admin-authoring-platform.md) — the scope-change record and
  the authoring workflow reference.

For the learner-side user guide, see the learner module's own documentation.
